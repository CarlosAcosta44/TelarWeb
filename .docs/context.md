# Contexto del Proyecto: Agencia TelarWeb

**TelarWeb** es una agencia de desarrollo web y soluciones digitales modernas. Nuestra misión es construir productos web rápidos, escalables y visualmente impresionantes para nuestros clientes, con un enfoque particular en negocios locales e iniciativas de mediano alcance.

## Objetivos del Sitio Web
1. **Presentación de Servicios**: Mostrar claramente qué hacemos (Desarrollo Web, E-commerce, Landing Pages, Consultoría UI/UX).
2. **Portafolio**: Exhibir proyectos pasados (como el caso de éxito de "Panadería Doña Elena") para generar confianza.
3. **Generación de Leads (Contacto)**: Un formulario robusto para que los clientes potenciales soliciten cotizaciones o agendas de llamadas.

## Fases de Planeación

### Sprint 1: Landing Page y Contacto
- Inicialización del proyecto bajo Clean Architecture.
- Hero de alto impacto (animaciones, tipografías modernas).
- Sección "Qué hacemos" (Servicios).
- Formulario de contacto funcional guardando *leads* en Supabase.

### Sprint 2: Portafolio y Casos de Éxito
- Creación de la sección del Portafolio.
- Páginas de detalle para proyectos específicos.
- Testimonios dinámicos de clientes.

### Sprint 3: Blog y Contenido
- Sistema básico de blog o artículos para mejorar el SEO y demostrar experiencia técnica en el sector.
